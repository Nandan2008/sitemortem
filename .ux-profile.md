# SiteMortem UX profile

Used by the VectorLab UX skills (ux-audit, anti-slop, colour-palette, typography, spacing, motion, viewports).

## Aesthetic reference
- Archetype: **Linear** (engineering tool). Near-monochrome neutrals, sharp 1px borders, one accent.
- Notes: brand accent is NVIDIA green `#76b900` (text variant `#3d6f00` light / `#8fd11f` dark). Teal appears only inside the hero headline gradient (marketing route).

## Accessibility
- Target: WCAG 2.1 AA contrast; axe-core must report zero violations on every view in both themes.
- Hit targets: WCAG 2.2 AA (24×24 minimum) on fine pointers; 44×44 on coarse pointers (`@media (pointer: coarse)`).

## Typography
- Inter; weights 400 / 500 / 600 only. Sizes: meta 12, secondary 14, body 16; headings scale up.

## Banned anti-aesthetics
- Default VectorLab ban list (glass, glows, rainbow/multi-hue CTAs, blob/mesh backgrounds, cartoon empties, decorative pills).
- No fabricated metrics or "AI confidence" numbers anywhere in the UI.

## Documented exceptions
- Owner-requested fading green background: one static, fixed full-window radial-gradient layer behind content (no blobs, no blur, no animation). All content sits on solid L1 surfaces above it.

## Voice
- Utilitarian and minimal. Sentence case. Verb-first actions.
