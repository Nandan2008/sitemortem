How a repair is made, and proven

  1. Detect

    axe-core finds WCAG violations. Playwright captures JavaScript errors and failed requests in real Chromium.

  2. Triage

    Nemotron Nano ranks every issue group in parallel so the highest-impact problems come first.

  3. Fix

    Ultra finds root causes, Super writes a minimal patch. It is validated, then applied to a temporary copy.

  4. Verify

    The audit runs again. A patch is kept only if the targeted issues are gone and nothing new appears; otherwise it is rolled back.

Summary metrics

How these numbers are calculated

Each issue is one unique finding (rule + page + element, or error message) from the browser audit. Every issue is in exactly one category, so accessibility + JavaScript + network always equals the total. Resolved is the total before minus the total now, and only drops after a patch is verified by a re-audit. Verified patches and rejected patches count patch attempts: verified means the backend re-audit confirmed the targeted issues are gone with nothing new; rejected includes rolled-back attempts and attempts that never produced a usable patch.

      Help

      Demo vs live

      Scripted demo makes no model calls. Patches are scripted and only cover the bundled storefront; the audit and every verification are real, and the UI labels it as scripted.

      Live calls NVIDIA Nemotron through Nebius Token Factory. It needs NEBIUS_API_KEY in .env. Live never falls back to scripted fixes: if something is misconfigured the run stops and says why. Tavily guidance is optional and reported as skipped if not configured.

      Reading patch statuses

      PROPOSED
      A patch passed validation and was applied to a temporary copy. It has not been checked yet.
      VERIFYING
      The browser audit is re-running against the patched copy.
      VERIFIED
      The re-audit confirmed the targeted issues are gone and no new issues appeared. The patch is kept.
      ROLLED BACK
      The patch applied but the re-audit failed it, so it was reverted. It is not part of the final patch.
      REJECTED
      No usable patch: the model output was invalid, matched nothing, or tried something not allowed. Nothing was applied.

      Troubleshooting

      • "Live mode needs NEBIUS_API_KEY": add the key to .env and restart the server.
      • Model not found / configuration problem: run python scripts/list_models.py and pin the IDs in .env.
      • Invalid ZIP: use a plain .zip of static files (HTML, CSS, JS, images, fonts). Executables, scripts, symlinks and absolute paths are rejected.
      • Connection lost: the page resumes the run automatically from the last event it saw; if that fails, start a new audit.
      • Chromium missing: run playwright install chromium.

      Limits, stated plainly

      • Automated testing covers only part of WCAG. A clean result is not a compliance certificate.
      • Generated alt text, labels and colours need human review before merging.
      • Static sites only; up to 6 linked pages; external hosts are blocked during the audit for safety.
